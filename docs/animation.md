# Animation

Fase 2 menambahkan:

- Hero reveal menggunakan animasi `fade-up`.
- Node jaringan digital bergerak perlahan.
- Lighthouse beam satu kali per sesi melalui `sessionStorage`.
- Sticky navbar mengecil saat scroll.
- Pulse lambat pada announcement strip yang dapat dipause.

Semua animasi menghormati `prefers-reduced-motion`. Lighthouse beam juga dinonaktifkan pada perangkat dengan `hardwareConcurrency <= 2`.
