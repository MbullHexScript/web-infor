# Accreditation Management

Tabel `accreditations` disiapkan untuk status akreditasi, lembaga, nomor keputusan, masa berlaku, sertifikat, status current, status public, dan verifikasi.

Status akreditasi dari website lama belum dipublikasikan karena belum lengkap. Halaman publik menampilkan pesan “Informasi akreditasi sedang diperbarui.” sampai data verified tersedia.
