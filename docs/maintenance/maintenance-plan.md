# Maintenance Plan

## Daily

- Check backup status.
- Check error logs.
- Check contact inbox.
- Check `/health`.

## Weekly

- Review failed jobs.
- Run broken link audit.
- Check storage usage.
- Review media without alt text.
- Update content as needed.

## Monthly

- Review dependency audit.
- Apply security updates on staging first.
- Run SEO report.
- Sample performance with Lighthouse.
- Review users/admin access.
- Run redirect audit.

## Semester

- Check curriculum and RPS.
- Verify lecturer data.
- Update academic schedule/calendar.
- Review PMB content.

## Annual

- Review accreditation data.
- Review management structure.
- Review alumni and statistics.
- Review privacy policy.
- Perform restore test.
