# Editorial Style Guide

## Indonesian

- Use the complete institutional name: Program Studi Informatika, Fakultas Sains dan Teknologi, UIN Sultan Maulana Hasanuddin Banten.
- Do not shorten the faculty name to only "Fakultas Sains" in official context.
- Use verified dates, names, academic titles, and document numbers.
- Do not publish fake statistics, fake accreditation data, fake PMB data, fake ISSN, or unverified claims.
- Keep CTAs direct and institutional.

## English

- Use "Informatics Study Program".
- Use "Faculty of Science and Technology".
- Use "Sultan Maulana Hasanuddin State Islamic University Banten".
- Keep academic terminology natural, not literal.
- Do not translate personal names, course codes, journal names, or official abbreviations unless explanation is needed.

## Content Review

Every production item should have:

- Verification status.
- Translation status.
- SEO title and description where applicable.
- Media source and alt text.
- Redirect decision for important legacy URLs.
