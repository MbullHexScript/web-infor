# Academic Module

Modul akademik menampilkan Kurikulum OBE 2026, struktur mata kuliah, detail mata kuliah, peminatan, repositori RPS, kalender akademik, jadwal kuliah, dan dokumen akademik.

## Publik

Data publik hanya menampilkan kurikulum published, mata kuliah aktif, dan data verified. RPS hanya tampil jika `is_public`, `is_current`, dan `status=published`.

## Admin

Admin dapat melihat dashboard akademik, menjalankan dry-run/commit import, dan mengunggah RPS PDF.

## Data Belum Lengkap

Nama Inggris mata kuliah, software pembelajaran, PDF RPS, kalender akademik, jadwal kuliah, dan dokumen akademik perlu dilengkapi saat dokumen resmi tersedia.
