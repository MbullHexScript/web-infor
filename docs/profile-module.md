# Profile Module

Modul profil mengelola halaman tentang Program Studi Informatika, sejarah, visi/misi/tujuan, sambutan Kaprodi, struktur pengelola, dosen, tenaga kependidikan, profil lulusan, akreditasi, dan kerja sama.

Data publik production hanya menampilkan data `verified`, kecuali konten statis yang sudah diverifikasi. Data legacy dari website lama disimpan sebagai `needs_review` agar admin dapat memeriksa sebelum publikasi final.
