# v1.0.0-rc.1 Release Notes

Status: draft, not tagged. Git is not available in PATH in this session, so no local tag was created.

## Features

- Public bilingual website modules through Phase 8.
- Admin dashboard and operations panels.
- Media library, SEO manager, redirect manager, audit log, backup smoke test, and health check.
- Phase 9 quality dashboard and audit commands.

## Data Migrated

- Curriculum OBE 2026 workbook data.
- Initial profile, information, research, student life, and settings seed data.

## Known Limitations

- RPS official PDFs are not uploaded.
- Lecturer data requires official verification.
- Some English course data is incomplete.
- Legacy content final migration is pending editorial review.
- Lighthouse/browser/accessibility screenshots require staging.
- Dependency audit reports Vite/esbuild advisories requiring a breaking upgrade decision.

## Security Status

No known critical application issue from local automated checks. Dependency audit and production infrastructure checks remain required.

## UAT Instructions

Use `docs/uat/uat-checklist.md` and do not approve production deployment until all critical items pass.

## Rollback Note

Use database backup, application release artifact, and `php artisan down` before rollback. Full rollback requires production backup configuration.
