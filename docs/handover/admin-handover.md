# Admin Handover

## Login dan 2FA

1. Buka `/admin/login`.
2. Masuk dengan akun admin resmi.
3. Aktifkan 2FA dari menu 2FA.
4. Simpan recovery codes di tempat aman.

## Dashboard

Dashboard menampilkan ringkasan konten, media, pesan, RPS, SEO, redirect, backup, dan status quality.

## Konten

- Berita, pengumuman, agenda, dan dokumen dikelola dari menu admin terkait.
- Data dosen, kurikulum, RPS, jurnal, prestasi, fasilitas, dan PMB harus diverifikasi sebelum dianggap final.
- Jangan memasukkan data fiktif untuk akreditasi, PMB, statistik, ISSN, atau RPS.

## Media

- Upload gambar/PDF dari Media Library.
- Isi alt text untuk gambar.
- Jangan upload file executable, arsip tidak jelas, atau dokumen privat.

## SEO dan Redirect

- SEO manager dipakai untuk metadata dan sitemap.
- Redirect manager dipakai untuk URL lama penting.
- Jangan redirect semua halaman lama ke homepage jika target relevan tersedia.

## Backup dan Quality

- Cek `/admin/operations` untuk backup/health.
- Cek `/admin/quality` untuk content verification dan RPS coverage.

## Logout

Selalu logout setelah selesai memakai perangkat bersama.
