# Search Console and Analytics

## Search Console

1. Create domain/property after production domain is active.
2. Verify ownership without committing tokens to the repository.
3. Submit `https://informatika.uinbanten.ac.id/sitemap.xml`.
4. Inspect homepage.
5. Monitor indexing, Core Web Vitals, coverage, and security issues.

## Analytics

Only enable analytics if approved.

Rules:

- Do not track admin pages.
- Do not capture contact form content.
- Exclude staging.
- Respect consent requirements if non-essential cookies are used.
