# Design System

Design tokens berada di `resources/css/app.css`. Warna dasar mencakup Lavender FST, ungu utama, deep purple, graphite, charcoal, silver, soft white, merah, kuning, dan cyan terbatas.

Komponen awal: navbar brand dengan logo resmi, theme toggle, public layout, dan admin layout.

Fase 2 menambahkan komponen publik modular:

- Top bar dan sticky glass navbar.
- Desktop dropdown navigation.
- Mobile drawer.
- Animated network dan lighthouse beam.
- Section cards untuk quick links, bidang keilmuan, jurnal, dan CTA.
- Empty state konsisten untuk konten yang belum terverifikasi.
