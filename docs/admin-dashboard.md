# Admin Dashboard

The main dashboard is available at `/admin`.

It summarizes published and draft content, active announcements, upcoming events, lecturers, courses, RPS coverage, research, achievements, contact messages, media storage, incomplete translations, pending verification items, redirect warnings, backup status, latest activity, and security posture.

Quick actions link to media, SEO, settings, backups, and content modules.

The dashboard is intentionally operational. It does not replace detailed CRUD pages for every module.
